# 使用者旅途與開發者經驗盤點

## 誰會用
| 角色 | 想完成的事 | 最在意 |
|---|---|---|
| 設計師／PM | 研究參考網站、做競品比較、拿來當設計起點 | 看得懂、能比較、能交給 Claude Design |
| 前端開發者 | 還原版面、取得 token、判斷技術棧 | 可直接貼進專案的產物、可重現 |
| 套件維護者（開發者經驗） | 改腳本不怕壞、能除錯、能擴充 | 測試、診斷、錯誤訊息、版本相容 |

## 旅途與缺口（第一版 → 本次處理）
| 階段 | 使用者遇到的問題 | 處理 |
|---|---|---|
| 1 安裝／啟動 | 要自己判斷 Node、瀏覽器、ffmpeg、網路是否可用；失敗訊息看不懂 | `doctor.mjs` 一次檢查並給出修復指令 |
| 2 執行 | 要記三支腳本和參數；中途失敗全部白跑 | `explore.mjs` 單一入口，分階段、有進度，單階段失敗不中斷其他階段 |
| 3 被擋住 | 遇到 403／驗證碼／Cookie 橫幅，結果是一堆空白頁卻看不出原因 | 偵測並標記 blocked，報告與儀表板明確提示；自動關閉常見 Cookie 橫幅 |
| 4 理解 | 儀表板只有「這次」的結果，沒有脈絡 | 資料庫累積歷史；儀表板加「與上次比較」「下一步」 |
| 5 比較／回頭找 | 做過 5 個網站就找不到誰用了 three.js、誰的主色偏藍 | SQLite 資料庫＋`db.mjs` 搜尋、比較、歷史 |
| 6 重用 | token 只有自訂 JSON，開發者還要自己轉 | 輸出 W3C Design Tokens 與 Tailwind 設定片段 |
| 7 信任 | 這工具會不會亂爬、爬了什麼 | 結果記錄 robots 規則、請求頁數、被擋原因；README 明列邊界 |

## 資料庫決策
- 用 Node 內建 `node:sqlite`：不需編譯原生套件（Mac 安裝不會失敗）、單一檔案 `~/.site-explorer/explorations.db`（可用 `SITE_EXPLORER_DB` 改位置）。
- 需要 Node ≥ 22.13；較舊版本時其他功能照常，只略過資料庫並提示升級。
- 只存結構化摘要（色彩、字型、平台、3D 元素、頁面），不存截圖與 HTML（它們留在輸出資料夾）。
- Claude 的 Artifact 資料庫是「分享給別人共同編輯」用，不適合當本機歷史庫；若要把團隊共用比較表做成 Artifact，可由資料庫匯出 JSON 再發佈。

## 開發者經驗
- `npm test`：用本機夾具網站（含 WebGL、CSS 3D、深色模式）端到端驗證爬取、匯出、資料庫、儀表板；沒有瀏覽器時自動略過瀏覽器測試。
- 所有腳本 `--help`、一致的退出碼、錯誤訊息說明下一步。
- 輸出結構帶 `schemaVersion`，之後改格式時資料庫可遷移。

## 反向驗證（假設它在使用者手上失敗了，會是為什麼？）
逐項用破壞性夾具實測，結果如下。凡是「確認」的都已修正並加入 `test/robust.test.mjs` 作為回歸測試。

| 假設的失敗 | 實測 | 處理 |
|---|---|---|
| 使用者輸入 `example.com`（沒打 https://） | ✅ 確認：只出現用法說明 | 自動補 scheme；本機與 IP 預設 http |
| 參數打錯（`--max-pages abc`） | ✅ 確認：悄悄爬 0 頁還顯示成功 | 數值驗證，明確報錯 |
| 網址跳轉到另一網域（apex → www） | ✅ 確認：只爬 1 頁，其餘連結被當外站 | 跟隨跳轉，www 視為同站，並重讀 robots |
| 頁面一直有請求不結束（分析追蹤碼） | ✅ 確認：單頁 47 秒 | 分段等待（load → 最多 5 秒 networkidle），降到 7 秒 |
| 無限捲動頁面 | ✅ 確認：爬取行程卡死 | 捲動限制 40 步／4 秒，另設單頁 120 秒看門狗 |
| robots.txt 全擋 | ✅ 確認：回報「0 頁」成功並產出無意義設計包；3D 擷取完全不看 robots | 明確說明並以代碼 3 結束，爬取與擷取都在啟動瀏覽器前檢查 |
| Cookie 橫幅處理誤點其他對話框 | ⚠️ 風險：選擇器含 `role=dialog`，可能點到「我同意條款」 | 只處理 cookie／consent 命名的容器，優先按「拒絕」；實測不誤點 |
| 惡意頁面內容注入儀表板 | 實測安全 | 加回歸測試 |
| 40000px 超高頁截圖失敗 | ❌ 不成立：正常完成 | 無需處理 |
| Mac 路徑含空格、儀表板圖片失效 | ❌ 不成立 | 加回歸測試 |
